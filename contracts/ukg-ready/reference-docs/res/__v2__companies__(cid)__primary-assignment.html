Employee Primary Assignment

GET

Retrieves a list of Primary Assignments for all employees who have an active and effective primary assignment on a given date.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • as_on_date
    string
    As Of Date. If not provided, current system date will be taken by default.
  • req_details
    string
    A comma separated string of all the details that are required. <br> <br> all -> Will fetch all the details for the assignment. <br> ccdetails -> Will fetch basic details + cost center details. <br> directRepManager -> Will fetch basic details + direct reporting manager details. <br> attributes -> Will fetch basic details + extra attributes details. <br> rates -> Will fetch rates for the assignment. <br><br>If not specified, only the basic details will returned.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
