HR Custom Fields

GET

Returns the employee hr custom fields. The Employee APIs use a separate security profile item to control access rights which is located in the company security profile in the following location: 1. Modules -> REST API Resources -> Employee HR Custom Fields -> View`. <b>Only the 'REST API RESOURCES' security profile items in combination with 'manager permissions' are considered by this REST API resource.</b>

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required
    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.

    Valid values: application/json, application/xml, text/xml
