Pay Calculation Profiles

GET

Returns the list of defined pay calculation profiles in the company when Pay Calculation 1 or 2 is enabled.

  • v2

Parameters

Path Parameters

    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
