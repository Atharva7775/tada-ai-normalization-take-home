Employees Based on Pay Group Id

GET

Retrieve employees information specific to pay group id.

  • dev

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • pay_group_id
    string
    required
    ID of the pay group (combination of pay period profile id-company ein id).
  • offset
    integer
    Offset query parameter for pagination.
  • limit
    integer
    Size of the fetched list. Default limit - 50. Max limit is default to 200.

Responses

Employees returned successfully.

Indicates that the server cannot process the request due to a client error (e.g., malformed request syntax, invalid request).

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/info
