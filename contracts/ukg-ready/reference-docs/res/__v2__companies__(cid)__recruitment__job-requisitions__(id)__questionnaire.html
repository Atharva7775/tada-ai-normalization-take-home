Job Requisition Questionniare questions

GET

Endpoint returns Questionniare questions of a Job Requisition. This is going to work without authentication

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    Job Requisition Id whose questionnaire is to be fetched.
Query Parameters
  • job_board
    integer
    Job Board. 1 for Indeed 2 for Seek 3 for LinkedIn

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/recruitment/job-requisitions/{id}/questionnaire
