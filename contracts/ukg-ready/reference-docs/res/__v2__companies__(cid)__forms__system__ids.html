System

GET

Endpoint returns list of the companies system forms for a period of time.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • form_types
    string

    Valid values: W2, W4, 1099MISCPRE2020, 1099MISC, 1099NEC, I9, LC2810, WH380E, WH380F, WH381, WH382, WH384, WH385, WH385V, CC305, TFNDECLARATION, SUPERANNUATION, CUSTOMFORMITEM, HMRCSTARTERCHECKLIST, T4, TD1, RL1, ROE

    Form types. If not specified, all types. Comma separated string for multiple types. <br><b>1099MISCPRE2020</b> - Returns all 1099 MISC forms before year 2020.</br> <br><b>1099MISC</b>- Returns all 1099 MISC form after 2019.</br>
  • modified_from
    date-only
    Used for getting forms which have been created or modified from date lower bounded. Should be in `yyyy-mm-dd` format. If modified_to is supplied, modified_from is required.
  • modified_to
    date-only
    Used for getting forms which have been created or modified to date upper bounded. Should be in `yyyy-mm-dd` format. Maximum difference between `from` and `to` dates can be 60 days. If modified_to is supplied, modified_from is required.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

Responses

If date range is not valid or invalid form type.

If there is any security violation.

If company or employee is not found.

Returned in case user is not authorized.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
