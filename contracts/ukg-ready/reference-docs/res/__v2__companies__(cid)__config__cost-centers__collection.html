Batch Upload

POST

Creates new cost centers within an existing cost center tree. The parent node of a cost center can be specified using different fields of the `parent_cc` reference object: `tree_index`, `tree_index` and `id`, or `tree_index` and `external_id`. If only `tree_index` is specified, the new cost center is created under the root node. If both `id` and `external_id` are specified, `external_id` is ignored and the search is performed using `id`. Requires a 'Cost Center Definitions add' permission to create new cost centers. The TLM, HR, or Scheduler subsystem must be enabled to update job strain. Requires at least one of the following subsystems: - TLM - TLM (Small Business Edition: PR/HR Version) - HR - HR (Small Business Edition) - Payroll - Scheduler
