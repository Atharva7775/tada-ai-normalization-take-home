POST

Endpoint for creating new Time Off Request. `TA|TALITE|HR` functionality must be enabled in company setup. This endpoint is for creating time off request either by an employee for self or by a manager on behalf of an employee. For all requests valid `timeoff` is a required field. Allowed time off request types are: - `FullDay` - `Partial` - `PartialBlk` - `Multiple` - `Dynamic` For `FullDay` request, from_date is required. For `Partial` day request, from_date, from_time and to_time are required fields. For `PartialBlk` request, from_date and total_time are required fields. For `Multiple` type request, from_date is a required field. For `Dynamic` type request, from_date and dynamic_duration are a required field. Allowed values for `dynamic_duration`: - `FULL_DAY` - `FIRST_HALF_OF_DAY` - `SECOND_HALF_OF_DAY` - `HALF_DAY` - `FILL_DAY` Date format for all date fields when requesting time off is `yyyy-mm-dd` format. Time format for all time fields when requesting time off is 24 hour `hh:mm:ss` format. `confirm_map` - the confirmation data for the request. The confirm map contains the code and the user response for the code. Code `0` is used to confirm a request. Any other value implies the user does not confirm the request and the request should not be created. The POST request returns an execute result set, which contains the success code on success. POST requests can return `info`/`confirm`/`critical`/`error`/`warning` message types. Info messages are benign and contain some information for the client. Other types of messages need a confirmation from the client to successfully create a time off request. The example json shows a warning message.
