Positions

GET

Return the information of all the Positions which are active and effective as on specified date(if not provided then today) . <br>API will also enable the consumer to specify what all detail he wants for the Position. <br>By default, only the basic Position details will be returned.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • as_on_date
    datetime
    Effective as of date. If not provided, current system date will be taken by default.
  • req_details
    string
    A comma separated string of all the details that are required. Possible values to be provided are : <br>1. all -> Will fetch all the details for the positions <br>2. ccdetails -> Will fetch basic details + cost center details. <br>3. directRepManager -> Will fetch basic details + direct reporting manager details. <br>4. attributes -> Will fetch basic details + extra attributes details. <br><br>Example : “all”, will fetch all the details. <br>“ccdetails” will fetch basic details and cost center details of the position. <br>“attributes, directRepManager” will fetch basic+attributes + rates + direct reporting manager details of the position.
  • page
    integer
    Page number. If not provided, then default value will be treated as 1.
  • size
    integer
    Items per page. Max limit is 200 per page. If not provided, then default value will be treated as 50.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
