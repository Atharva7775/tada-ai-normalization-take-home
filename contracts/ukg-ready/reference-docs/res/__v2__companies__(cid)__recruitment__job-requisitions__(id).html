Job Requisition Details

GET

Endpoint returns details of specific Job Requisition.

  • v2

Parameters

Path Parameters

    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    Job Requisition Id whose details are to be fetched. This is going to work with authentication.
