Rate Tables

GET

Get all rate tables (comany and personal) configured in the company.

  • v2

Parameters

  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

  • type
    string

    Valid values: COMPANY, PERSONAL

    Query parameter to filter rate tables by type.
  • page
    integer
    Page number.
  • size
    integer
    Iitems per page.

    Valid values: application/json, application/xml, text/xml

    Default: application/json
