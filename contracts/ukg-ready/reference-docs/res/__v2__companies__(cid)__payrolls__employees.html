Employees

POST

Allows caller to fetch list of employees based on request filter criteria i.e. EIN, pay period profile and employee list. The body of the request varies depending on the filter criteria. If no filter is provided then all account having active and non-deleted EIN and pay period profile assigned will returned.

  • dev

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Employees returned successfully.

Indicates that the server cannot process the request due to a client error (e.g., malformed request syntax, invalid request).

The supplied credentials are not sufficient to access the resource.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/payrolls/employees
