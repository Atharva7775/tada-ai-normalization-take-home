Time Off Calendar Sync

GET

Endpoint to sync time off calendar for an employee to a personal calendar.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required
    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • syncToken
    string
    required
    Calendar Sync token.

Responses

Forbidden - Security violation.

Not Found - Company not found.
