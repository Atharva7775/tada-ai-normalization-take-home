Account Assignments

GET

Returns the information of all the Current, Future or Only Past Dated assignments of the Account. Although past and future dated assignments will be governed by query parameter.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • account_Id
    string
    required
    Unique id of an Account which is used to fetch assignment details of the particular mentioned account id.
Query Parameters
  • req_details
    string
    Two possible values for this parameter are : <br>1. basic -> Will return basic assignment details like assignment id, assignmnent start date, assignee details etc. <br>2. all -> Will fetch all the details for the assignment including basic details, cost center details, direct reporting manager details, assignment attributes details, rate details for the assignment. <br>If not provided, the default value of this parameter is basic.
  • include_future_assignments
    boolean
    If set as true, the result set will contain future dated assignments also. <br>If not provided, the default value of this flag is false.
  • only_past_assignments
    boolean
    If set as true, the result set will contain only past dated assignments. <br>If not provided, the default value of this flag is false.
  • since
    datetime
    Used to set reference date to determine the date starting from which we have to pick all the past assignments till today minus 1 day. <br>If not provided, the default value of this parameter will be minimum possible date in the system.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json
