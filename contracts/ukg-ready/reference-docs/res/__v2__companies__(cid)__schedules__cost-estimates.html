Schedule Employee Cost Estimates

GET

Returns a list of cost estimates for each schedule, giving both the full schedule estimated costs for each employee on each schedule, and the daily cost estimates for each employee on each schedule. (If no from and to parameters are provided, the default date range is from the first day of the previous month to the first day of the next month (2 months). A date range longer than a quarter (3 months/93 days) is not allowed.)

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • from
    date-only
    Schedule Date Range filter. (Min date)
  • to
    date-only
    Schedule Date Range filter. (Max date)
  • schedule_ids
    string
    Schedule IDs
  • account_ids
    string
    Account IDs to filter schedule employees; when omitted, all employees are included
