Job Requisitions

GET

Endpoint returns List of Job Requisitions available within the company. This is going to work with Authentication.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • job_locations
    string
    Query parameter for job locations to filter out records.
  • job_categories
    string
    Query parameter for job categories to filter out records.
  • keywords
    string
    Query parameter for keyword based filtering.
  • offset
    integer
    Offset query parameter for pagination.
  • size
    integer
    Lot size query parameter for pagination.
  • include_all
    boolean
    Query parameter to fetch all records.
  • ein_id
    integer
    Query parameter used to fetch job details of specific EIN.

Responses

Returned when invalid EIN Id is given as query parameter.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/recruitment/job-requisitions
