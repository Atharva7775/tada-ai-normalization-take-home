Grants

GET

Gets all active authorized OAuth applications for a specified user within a company. The user sending the request must either be the same as the specified user or have permission to view other users' grants.

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • accountId
    integer
    required
    The ID of the user whose grants to access.

Responses

The authorized applications are returned.

The user calling this endpoint is trying to access the grants of a user other than themselves and does not have permission to do so.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/oauth2/grants
