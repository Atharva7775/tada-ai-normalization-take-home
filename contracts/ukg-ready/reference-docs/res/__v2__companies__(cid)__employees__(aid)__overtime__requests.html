Overtime Requests

GET

Endpoint for fetching employee overtime requests within required date range. Date range should be less than or equal to 366 days. To fetch own overtime requests, user must have 'Request Overtime' permission. To fetch employees overtime requests, user must have 'Approve', 'Create' or 'Edit' 'Overtime Requests' permission. Requires "TLM" subsystem.

  • v2

Parameters

Path Parameters
  • cid
    string
    required
    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required
    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • date_from
    date-only
    required
    Defines a lower bound of the date range for overtimes.
  • date_to
    date-only
    required
    Defines an upper bound of the date range for overtimes.
  • state
    string

    Valid values: NEW, APPROVED, ACCEPTED_BY_EMPLOYEE, REJECTED, MODIFIED, REJECTED_BY_EMPLOYEE, DELETED

    A state of the required overtime requests.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/overtime/requests
